# Nishita Bhandary — Minimal Interactive Portfolio

This version is intentionally designed like a refined digital presentation rather than a conventional long scrolling portfolio.

## Structure
1. Home
2. About
3. Skills
4. Case Studies
5. Experience & Achievements
6. Contact

Use the **Next** button, the right-side dots, keyboard arrow keys, or swipe on mobile to move between sections.

## Files
- `index.html` — portfolio structure
- `style.css` — visual design
- `script.js` — section navigation and case-study interaction
- `resume/Nishita_Bhandary_Resume.pdf` — resume

No photos or decorative illustrations are used.
